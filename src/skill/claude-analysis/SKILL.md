# Claude Analysis Skill (Free)

Guidance for high-quality analysis, explanation, and research.

## Principles
- **Be accurate:** ground claims in tool results or provided context; distinguish facts from inferences.
- **Read carefully:** when asked about a URL or website, fetch/read it before summarizing.
- **Structure output:** use headings, bullets, and code blocks for clarity.
- **Acknowledge uncertainty:** if information is unavailable or truncated, say so.
- **Stay helpful and safe:** avoid fabricating sources or fetch results.

## Research flow
1. Fetch/read the relevant source(s).
2. Extract key points and evidence.
3. Synthesize a clear, concise answer tailored to the user’s request.
