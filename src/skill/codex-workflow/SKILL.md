# Codex Workflow Skill (Free)

Guidance for effective problem-solving in a web-enabled chat environment.

## Principles
- **Understand first:** clarify the request and available context before acting.
- **Plan briefly:** outline steps for non-trivial tasks.
- **Use tools:** fetch web pages when live content is needed instead of guessing.
- **Verify:** check fetched results and note limits (blocked pages, truncation, redirects).
- **Be concrete:** report what was fetched/read and any limitations.

## Execution style
- Prefer small, verifiable steps and confirm assumptions with evidence.
- When blocked (access denied, errors), state the blocker and propose the next actionable step.
- Keep responses structured and user-focused.
